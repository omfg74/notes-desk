# Заметки

Локальный harness для текстовых заметок. Он открывает одну папку и может только читать её, создавать заметки `.md` и `.txt` и заменять в заметке один уникальный фрагмент. Команд, сборки и доступа вне папки нет.

`notes-desk` открывает обычное окно программы. Страница та же, но это не вкладка браузера: её рисует системный webview. Так работает на Linux, Windows и macOS. Сервер слушает только `127.0.0.1`.

Версия 0.2.0 по-прежнему сырая: одна папка и текстовые заметки. На iPad этого окна нет.

На Linux для окна нужны пакеты `gir1.2-webkit2-4.1` и `gir1.2-javascriptcoregtk-4.1`. На Windows используется WebView2, на macOS — системный WebKit.

## Установка

Пакет берётся из релиза. Вместо `vX.Y.Z` подставьте нужный тег со страницы релизов.

```bash
pipx install "git+https://github.com/omfg74/notes-desk.git@vX.Y.Z"
notes-desk
```

На Linux перед этим поставьте `gir1.2-webkit2-4.1`, `gir1.2-javascriptcoregtk-4.1` и `python3-gi`. Если окно пишет, что нет `gi`, поставьте ту же версию так:

```bash
pipx install --system-site-packages "git+https://github.com/omfg74/notes-desk.git@vX.Y.Z"
```

## Релизы

Номер версии в `pyproject.toml` и в `notes_desk/__init__.py` должен совпадать.

1. Поменять номер в обоих местах и закоммитить это в `main`.
2. Поставить тег с тем же номером и отправить его:

```bash
git tag vX.Y.Z
git push origin vX.Y.Z
```

GitHub Actions сверяет тег с номером, запускает `notes-desk --check`, собирает пакет и создаёт релиз с этим тегом. Отдельной ручной публикации нет.

## Запуск из папки проекта

```bash
python3 -m notes_desk
```

Ключ и модель можно задать в окне, в блоке «Модель». Адрес — корень OpenAI-совместимого API, без `/chat/completions`. Пустое поле ключа при сохранении уже введённый ключ не стирает.

Те же значения можно передать при запуске:

```bash
NOTES_DESK_BASE_URL=https://api.openai.com/v1 \
NOTES_DESK_MODEL=имя-модели \
NOTES_DESK_API_KEY=ключ \
python3 -m notes_desk
```

Ключ остаётся в памяти процесса и в репозиторий не пишется. После остановки его нужно задать снова, если он не в переменной окружения.

Проверка без модели и без сети:

```bash
python3 -m notes_desk --check
```

## iPad

Эту версию на iPad не поставить: страница не открыта в сеть. Позже тот же экран можно будет открыть с планшета по домашнему Wi‑Fi, если сервер будет слушать адрес компьютера и пускать в папку только с паролем. Отдельное приложение в App Store для этого не требуется.
