# Заметки

Локальный harness для текстовых заметок. Он открывает одну папку и может только читать её, создавать заметки `.md` и `.txt` и заменять в заметке один уникальный фрагмент. Команд, сборки и доступа вне папки нет.

Окно — страница на этом компьютере: `http://127.0.0.1:8765`. Сервер слушает только `127.0.0.1`.

Версия 0.1.0 сырая: одна папка, текстовые заметки, без iPad и без доступа из сети.

## Установка

```bash
pipx install "git+https://github.com/omfg74/notes-desk.git@v0.1.0"
notes-desk
```

## Запуск из папки проекта

```bash
python3 -m notes_desk
```

Ключ и модель можно задать в окне, в блоке «Модель». Адрес — корень OpenAI-совместимого API, без `/chat/completions`. Пустое поле ключа при сохранении уже введённый ключ не стирает.

Те же значения можно передать при запуске:

```bash
NOTES_DESK_BASE_URL=https://api.openai.com/v1 \
NOTES_DESK_MODEL=имя-модели \
NOTES_DESK_API_KEY=ключ \
python3 -m notes_desk
```

Ключ остаётся в памяти процесса и в репозиторий не пишется. После остановки его нужно задать снова, если он не в переменной окружения.

Проверка без модели и без сети:

```bash
python3 -m notes_desk --check
```

## iPad

Эту версию на iPad не поставить: страница не открыта в сеть. Позже тот же экран можно будет открыть с планшета по домашнему Wi‑Fi, если сервер будет слушать адрес компьютера и пускать в папку только с паролем. Отдельное приложение в App Store для этого не требуется.
